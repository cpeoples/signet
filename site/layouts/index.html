Every answer comes from Apple

1

Signing status from Apple

For each firmware, Signet sends a signing request to gs.apple.com. If Apple returns a signature, it's signed. Nobody types that in by hand.

2

Firmware lists from Apple

IPSW and OTA lists come from Apple's update servers (mesu.apple.com, gdmf.apple.com). Board, chip and display details come from the firmware itself.

3

Downloads straight from Apple

Download buttons point to updates.cdn-apple.com. Signet never hosts, changes or proxies a file. Check the SHA-1 on each page against your download.
